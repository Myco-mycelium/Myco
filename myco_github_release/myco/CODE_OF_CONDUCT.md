# Code of Conduct

## Our community

Myco is built by an individual learning in public, with help from the community. Everyone who uses, contributes to, or participates in Myco — in any capacity — is part of that community.

We want this to be a place where people of all skill levels, backgrounds, and experience feel welcome. That includes beginners who have never written a line of code. Especially them.

---

## The short version

**Be kind.** Treat people the way you want to be treated.

That is genuinely it. Everything below is just explaining what that means in practice.

---

## What we expect

### Be welcoming
Not everyone knows what a "pull request" is. Not everyone understands Python. That is fine. Help them. Point them to the right documentation. Answer their questions without making them feel stupid.

### Be patient
Myco is a complex project. Sometimes things break. Sometimes questions take a while to answer. Sometimes PRs take time to review. Patience makes everything work better.

### Be constructive
If something is wrong, explain how to fix it. "This is broken" is less useful than "This breaks because X; try Y instead."

### Assume good intentions
Most people asking questions are genuinely curious. Most people submitting code are genuinely trying to help. Start from that assumption.

### Give credit
If someone helped you solve a problem, say so. If you used someone's idea, mention them.

---

## What we do not accept

- Insults, name-calling, or personal attacks
- Harassment of any kind — public or private
- Dismissing questions as "too basic" or "stupid"
- Gatekeeping based on skill level, background, or experience
- Making people feel unwelcome because they are new to coding, new to AI, or new to open source

---

## On Discord

The Discord server ([discord.gg/NTGWzPy4yB](https://discord.gg/NTGWzPy4yB)) follows the same rules. Additionally:

- Keep discussions in the right channels
- Do not spam or post the same message multiple times
- Do not DM people unsolicited to ask for help — use the help channels so others can benefit too
- Treat the server as a shared space, not a personal support desk

---

## Reporting problems

If someone is making the community unwelcoming, you can:

1. **On GitHub:** Use the "Report" option on the comment or issue, or email GitHub Trust & Safety
2. **On Discord:** DM a moderator or use the `/report` command

You will not be ignored. Reports are taken seriously.

---

## This is a learning project

The creator of Myco is learning as they build it. The documentation has gaps. The code has rough edges. Some decisions might be wrong. That is okay. It is how learning works.

If you find something that could be better — code, documentation, process, anything — the right response is to help fix it, not to criticise. We are all figuring this out together.

---

*This code of conduct applies to all Myco spaces: GitHub issues, pull requests, discussions, and the Discord server.*
